About NEXUS

A Federated Learning-Based Privacy-Preserving IoT Intrusion Detection System.

Major Project

PROJECT OVERVIEW

Intelligent IoT Network Security

NEXUS is a prototype intrusion detection platform that explores centralized and federated learning approaches for classifying IoT network traffic. It compares model performance under IID and Non-IID client data distributions.

Project Objectives

What this system aims to achieve

Intrusion Detection

Identify benign and potentially malicious IoT network traffic.

Federated Learning

Explore collaborative model training across simulated clients.

Model Comparison

Evaluate centralized, IID FedAvg and Non-IID FedAvg approaches.

Visual Monitoring

Present prediction summaries and model evaluation through a dashboard.

System Workflow

High-level processing pipeline

01

Dataset Collection

CICIoT2023 network traffic dataset is used for experimentation.

02

Data Preprocessing

Feature selection, data cleaning, scaling and label encoding.

03

Model Training

Centralized training and simulated federated training using FedAvg.

04

Model Evaluation

Compare accuracy, macro F1-score and weighted F1-score.

05

Traffic Prediction

Flask application processes uploaded CSV files and generates predictions.
